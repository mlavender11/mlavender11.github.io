Developed a C++ Boids simulator based on Craig Reynolds' algorithm to model and visualize flocking behavior.

## Highlights

- Implemented the core separation, cohesion, and alignment rules.
- Extended the model with predator and prey boids that use pursuit and evasion behaviors.
- Applied object-oriented programming principles, including encapsulation, abstraction, and inheritance, to modularize the behavioral and visual systems.

## Tools

C++ and object-oriented design.
